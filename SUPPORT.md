# Support

Use GitHub Issues for reproducible bugs, feature proposals, and documentation
problems. Include the version or commit, deployment mode, expected behavior,
actual behavior, and a minimal reproduction with secrets and personal data
removed.

Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.

This is a community-maintained project without a guaranteed response time or
commercial support commitment. Deployment-specific questions should include the
relevant non-sensitive configuration and logs.
