# 技术面试智能体安全威胁模型

| 项目 | 内容 |
| --- | --- |
| 文档版本 | v0.7 |
| 文档状态 | 私有与共享内部资料安全边界已落地 |
| 更新日期 | 2026-10-23 |
| 依据 | 需求 v1.6、`AGENTS.md` 安全底线 |

> 本文覆盖 P0 的主要安全、隐私和权限边界。`DR-01` 至 `DR-09` 已批准，ADR-0001 至 ADR-0010 已接受；账号、认证、提交与进行中反馈、结束控制、删除后证据摘要、最小审计、首个用户可见切片、私有资料和共享资料按本文冻结。

## 1. 信任边界

| 边界 | 不可信内容 | 控制 |
| --- | --- | --- |
| 浏览器 -> API | 请求参数、文件、回答、URL | 登录、Schema 校验、文件校验、CSRF/会话保护 |
| 用户输入 -> Prompt | 题目、回答、简历文本 | 包裹为 `<untrusted>`，不能改变系统指令 |
| 检索结果 -> Prompt | 系统文档片段、个人资料片段、题库内容 | owner 过滤、allowlist、版本固定、`<untrusted>`、片段长度限制 |
| Worker -> LLM | 结构化业务上下文 | 最小化字段、trace、token/时长上限 |
| API -> 对象存储 | 上传文件 | 随机键、私有桶、短时授权 |
| 运维日志 | trace、错误、指标 | 脱敏、禁止正文和密钥 |

## 2. 威胁与控制

### 2.1 资源越权

风险：

- 通过猜测 UUID 查看他人简历、问答、面试和错题。
- 通过修改请求体中的 `owner_user_id` 或资源 ID 横向越权。
- 通过错误差异判断资源是否存在。

控制：

- 服务层所有查询都带 `owner_user_id = current_user.id`。
- 资源不存在和他人资源统一返回 `404 resource_not_found`。
- 不信任客户端传入所有者字段；所有权由会话派生。
- 测试覆盖读、写、删除、SSE、报告、导出和 Worker 回调。

### 2.2 认证与会话

风险：

- 登录凭据暴力尝试。
- 会话固定、CSRF、XSS 窃取 Cookie。
- 撤销会话后旧请求仍有效。

控制：

- 密码使用 Argon2id；注册、登录和密码重置接口按来源和标准化账号维度限流。
- 登录失败统一返回 `401 invalid_credentials`；注册和找回密码统一返回中性 `202`，不通过响应状态、错误码或文案区分账号存在性。
- 注册不签发会话；登录是唯一会话签发入口。并发注册命中唯一约束时仍走相同中性响应。
- `interview_session` 使用 `HttpOnly`、`Secure`、`SameSite=Lax`；`interview_csrf` 是前端可读的 verifier，写请求同时执行 `X-CSRF-Token` 与 Origin/Referer allowlist 校验。
- 会话令牌与 `auth_sessions.csrf_token_hash` 都只保存哈希；支持撤销和过期，撤销后请求立即失效。
- 密码重置令牌只保存哈希、短时有效、单次使用；成功重置后撤销该账号全部旧会话。
- 邮件发送失败不得阻塞注册或登录，也不得变成账号枚举信号。
- 前端不把会话令牌写入 URL、日志或 localStorage。
- `web/` 只从 `interview_csrf` 读取 CSRF verifier，并放入 `X-CSRF-Token`；`interview_session` 对脚本不可读。
- 首版不接第三方 OAuth 和短信验证码。

已落地证据：

- `web/` 已实现注册、登录、退出、找回/重置密码、空工作台、四类历史分页和响应式导航。
- 浏览器测试检查 `interview_session` 与 `interview_csrf` 的 Cookie 属性、写请求令牌、会话失效和密码重置后的旧会话撤销。
- 历史请求只返回 `{items, next_cursor}` 形式的当前用户资源，不暴露跨用户数据。

### 2.3 Prompt 注入与角色绕过

风险：

- 简历、题目、回答或检索片段包含“忽略之前指令”。
- 用户诱导系统泄露参考答案、评分标准或内部 Prompt。
- 用户要求扩展知识源或访问外部 URL。

控制：

- 所有外部内容放入 `<untrusted>` 块，系统 Prompt 明确只作为数据。
- 工具输入 Schema 不允许任意 URL；知识源 ID 必须来自 allowlist。
- 评分只使用受保护的服务端材料，公开 DTO 不返回参考答案。
- Prompt 和模型输出不拥有权限、状态迁移和总预算控制权。
- 安全、越权和提示注入类 eval 必须 100% 通过。

### 2.4 答案泄露

风险：

- 面试进行中通过报告、错题或调试接口提前拿到答案。
- 通过错误信息、SSE 事件或缓存拿到未授权字段。
- 前端源码或网络响应包含隐藏评分材料。

控制：

- 服务端响应 DTO 裁剪，而不是前端隐藏。
- 受保护内容只在整场终态且报告可用后解锁。
- API 和 SSE 使用同一权限与状态检查。
- 测试覆盖进行中报告、错题详情、SSE completed、重复提交和越权请求。
- 回答提交只返回 `202`、接收时间和中性进度；内部评分通过独立 DTO 边界裁剪，整场终态且评分完成后才解锁详细反馈。
- 进行中查询和 SSE 只允许中性流程、已提交轮次、完成数、剩余题数和时间，不返回趋势、预测分数、关键错误或追问触发依据。
- P0 只允许结束当前追问链；提前结束整场在 P1 使用独立操作和二次确认，防止误操作扩大影响范围。

### 2.5 文件上传

风险：

- MIME 欺骗、超大文件、压缩炸弹、损坏 PDF/DOCX。
- 文件名路径穿越、恶意宏或扫描件误处理。
- 对象存储公开访问。

控制：

- 校验扩展名、声明 MIME、魔数、大小和页数。
- 文件名仅作为展示文本，不作为对象键或路径。
- 使用独立私有桶和随机对象键，访问通过短时会话。
- 不支持格式和扫描件明确拒绝；P0 不做 OCR。
- 解析和模型调用设置超时、页数、文本长度和 token 上限。
- 文件读取在受限进程或库配置下执行，错误不返回内部路径。

### 2.6 数据删除与保留

风险：

- 用户删除后仍能通过历史、搜索、导出或 SSE 看到数据。
- 对象存储删除失败但没有告警。
- 审计日志反向保留简历正文或完整回答。

控制：

- 删除先写墓碑，立即阻断业务可见性，再异步清理对象和衍生数据。
- 删除任务有租约、重试、失败告警和审计摘要。
- 历史、搜索、报告、错题和导出统一检查删除状态与到期时间。
- 删除原始简历后，分析、题目和报告证据只保留最长 200 字符的脱敏摘要，并标记 `source_deleted`。
- 删除事务清除原文引用、页码、章节、文件名、字符区间和可拼接上下文；无法安全脱敏的证据必须删除。
- 审计只保留操作类型、资源类型内部枚举、哈希化资源 ID、结果、时间和请求 ID，固定保留 365 天。
- 审计禁止保存原始用户 ID、业务正文、完整回答、证据原文、凭据或可逆个人标识。
- 保留期任务按 30/90 天规则执行，不依赖客户端触发。
- 365 天到期后删除或不可逆匿名化审计记录，禁止把审计转为可关联的长尾分析数据集。

### 2.7 日志与敏感信息

风险：

- 把简历正文、回答、证据、Cookie、API Key 或模型原始输出写入日志。
- 手机号、邮箱、token 等进入错误追踪系统。

控制：

- 统一日志出口对手机号、邮箱、token、身份证号等正则打码。
- 结构化日志字段使用 allowlist；禁止 `print(payload)` 调试后提交。
- 模型调用 trace 只记录元数据、用量和摘要，不记录完整 Prompt/答案。
- 审计事件使用资源 ID 哈希和操作枚举。
- 严格字段 allowlist 在审计写入层执行，禁止通用 metadata 或自由文本错误被透传。
- 日志或 trace 测试纳入 CI。

### 2.8 检索和知识源污染

风险：

- 未批准来源或旧版本文档进入回答。
- 检索片段过长导致上下文污染和成本失控。
- 用户通过查询词注入知识源配置。
- 个人资料通过共享索引、证据 DTO 或缓存跨 owner 泄露。
- 删除后的个人资料仍被向量或词法索引召回。

控制：

- 知识源版本在请求开始时冻结；历史证据不跟随更新。
- 查询计划和来源选择由受控服务构造，客户端只能提交问题。
- 结果按 allowlist、相关性、版本、去重和长度裁剪。
- 关键事实必须引用证据 ID；无证据时明确模型知识或拒答。
- 检索工具输出超过 2000 字符统一截断并注明原长度。
- 个人资料所有查询同时过滤 `owner_user_id`、`state='ready'`、`deleted_at IS NULL` 和未到期条件；向量与词法候选都执行相同 owner 过滤后才进入 RRF。
- 个人资料不进入 `knowledge_sources` allowlist；系统资料与个人资料只在本请求的冻结证据集合内融合。
- 上传正文、chunk、向量和检索片段在进入 Prompt 前放入 `<untrusted>`，系统 Prompt 明确块内内容只能作为数据，不能改变检索范围或引用规则。
- 公开证据只返回 `citation_id`、标题、章节、200 字符摘要、相关度、`source_kind` 和 `source_state`，不返回 owner ID、chunk UUID、对象键或完整正文。
- 删除个人资料时先写墓碑并更新历史证据为 `source_deleted`，再异步删除 chunks 和对象；Worker fencing 防止迟到任务复活已删除资料。
- 原资料默认保留 90 天；到期清理与用户删除都阻断后续检索，并纳入保留任务审计。

### 2.9 幂等与重放

风险：

- 网络重试导致重复评分、重复追问、重复错题或重复扣费。
- 相同幂等键被用于不同请求体。
- 截止后重放旧提交。

控制：

- 数据库唯一约束是幂等事实来源。
- 相同键不同请求体返回冲突。
- 轮次只接受一次回答；错题按 `turn_id` 唯一写入。
- 提交事务同时校验服务端截止时间。
- SSE 重连不重新执行完整模型调用。

### 2.10 资源耗尽和成本失控

风险：

- 长输入、无限追问、无限检索、循环无上限导致账单暴涨。
- 用户并发请求耗尽模型或数据库连接。

控制：

- Agent 三重封顶：最大步数、token、总时长；嵌套深度 <= 2。
- 面试整场 40 分钟、单链 2 层和 3 次回答，预算持久化。
- 检索限制查询次数、结果数、片段长度和 token。
- 用户和 IP/账号维度限流；SSE 连接数受限。
- 完整面试成本 P95 <= ¥3.00 进入发布门禁。
- 超限返回结构化错误，不静默重试或扩大预算。

### 2.11 异步任务与并发

风险：

- Worker 重复领取或崩溃导致任务卡死。
- 截止、评分和报告并发写导致状态回退。
- 删除任务和生成任务同时执行。

控制：

- `FOR UPDATE SKIP LOCKED`、租约、指数退避和死信状态。
- 状态迁移使用条件更新和期望旧状态。
- 删除墓碑优先于结果生成；生成前再次校验资源可见性。
- 所有 Worker 循环受关闭信号和最大运行时长控制。

## 3. 测试清单

### 安全

- 未登录、过期会话、撤销会话；注册后未登录不得获得会话。
- 新邮箱与已存在邮箱注册返回相同状态码和响应体；重复请求触发限流。
- 错误密码与不存在邮箱返回相同登录失败语义。
- 重置令牌过期、已使用、被撤销和并发重放均被拒绝；重置成功后旧会话全部失效。
- 邮件服务故障不影响注册和登录。
- 越权读、写、删、SSE、报告和跨用户分页。
- `interview_session`/`interview_csrf` 双 Cookie、`X-CSRF-Token`、缺失或错误 CSRF、XSS、开放重定向和任意 URL。
- 文件类型欺骗、超大文件、超页、损坏文件、路径穿越。
- Prompt 注入、角色切换、答案泄露和内部字段泄露。
- 日志脱敏、错误响应不含堆栈和 Prompt。

### 数据

- 原始简历删除后所有入口不可见。
- 删除后证据摘要不超过 200 字符，不含原文引用、页码、章节、文件名或可拼接上下文。
- 删除后从历史、报告、问答、错题、导出和 SSE 均无法恢复原始正文。
- 30 天和 90 天到期任务。
- 删除任务失败重试和审计摘要。
- 审计字段白名单、资源 ID 不可逆和 365 天到期删除/匿名化。
- 历史证据固定版本，不被新知识源覆盖。
- 其他 owner 的资料、未 ready 资料、已删除资料和过期资料都不进入问答证据。
- Ollama 不可用时降级词法检索，不把个人资料转换为系统资料或放宽 allowlist。
- 个人资料删除后历史证据只显示 `source_deleted`，重新提问不再召回。

### 一致性与预算

- 并发提交回答只评分一次。
- 重复幂等键相同请求返回首次结果。
- 不同请求体冲突。
- 截止前后提交的确定性结果。
- 追问深度、轮次、token 和时间预算恢复不重置。
- 跳过、结束当前追问链和 P1 结束整场分别记录原因，不互相覆盖。
- P0 结束当前追问不设置整场终态，未展示主问题保持有效。
- 评分失败不写错题，报告不提前解锁。

## 4. 上线阻断条件

- 任一安全关键 eval 低于 100%。
- 存在可复现的跨用户数据访问或答案提前泄露。
- 截止时间可由客户端绕过。
- 删除后仍可通过任何业务入口看到原始数据。
- 删除后证据仍能通过片段、位置、文件名或上下文恢复正文。
- 审计包含业务正文、原始用户 ID 或超过 365 天的可关联记录。
- 日志包含简历正文、完整回答、密钥或未脱敏敏感信息。
- 无界循环、无界重试或可绕过 trace 的模型调用。
- 完整面试成本或行为评测不达发布门槛。
